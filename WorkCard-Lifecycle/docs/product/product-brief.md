# Product Brief v1

## Проблема

Производственная работа проходит через выпуск, назначение, выполнение и контрольные точки. Без единой цифровой карточки трудно определить текущее состояние работы, ответственного, допустимое следующее действие и основание для начисления нормо-часов.

## Пользователи MVP v1

| Пользователь | Основная задача |
|---|---|
| Планировщик | Создать синтетическую партию и выпустить комплект карточек |
| Мастер | Массово назначить карточки и подтвердить выполнение |
| Исполнитель | Начать и завершить назначенную работу |
| Контролёр БТК | Подтвердить качество выполненной карточки |
| Администратор / аудитор | Просмотреть историю и выполнить mock payroll export |

Один демонстрационный пользователь может переключать роли. Полноценное управление учётными записями и сложная ролевая модель не входят в MVP.

## Ценность

- отдельная цифровая карточка на каждый экземпляр;
- прозрачное состояние и ответственность;
- управляемые переходы между ролями;
- защищённые бизнес-инварианты;
- воспроизводимая история действий;
- прослеживаемая связь закрытой работы с mock нормо-часами.

## Основной продуктовый сценарий

Создать партию → выпустить карточки → массово назначить → выполнить → подтвердить мастером → подтвердить БТК → закрыть → экспортировать в mock payroll → просмотреть audit log.

## Граница системы

Приложение самостоятельно хранит синтетические производственные данные и имитирует внешнюю payroll-интеграцию. Оно не подключается к реальному предприятию и не заменяет MES, ERP или расчёт зарплаты.

## Результат MVP

Работающий браузерный сценарий, подтверждённый API, БД, audit log и автоматическими тестами ключевых правил.
