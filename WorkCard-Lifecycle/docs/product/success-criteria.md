# Success Criteria v1

## Критерии успеха

- пользователь проходит весь happy path через браузер;
- партия из `N` экземпляров создаёт ровно `N` уникальных карточек;
- запрещённые действия недоступны в UI и отклоняются API;
- audit log позволяет восстановить хронологию карточки;
- повторный mock payroll export не создаёт второе начисление;
- проект разворачивается с чистого окружения по README;
- критические правила подтверждены автоматическими тестами;
- публичная демонстрация не требует ручного исправления данных.

## Критерии готовности MVP

- все обязательные функции из [[mvp-scope]] реализованы;
- нет открытых критических дефектов;
- CI проходит;
- staging и production отвечают health check;
- документация соответствует реализации;
- demo script воспроизводим;
- ограничения и синтетическая природа case study указаны явно;
- выполнен финальный аудит из [[project-plan]].

## Не является критерием успеха

- количество функций вне scope;
- сходство с полноценной MES;
- наличие AI или сложной аналитики;
- использование максимально сложного технологического стека.
