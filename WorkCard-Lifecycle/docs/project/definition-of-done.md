# Definition of Done

## Для артефакта документации

- цель и границы файла понятны без устного пояснения;
- нет противоречий с принятым [[mvp-scope]];
- спорные решения связаны с ADR или [[decision-log]];
- есть объективные критерии проверки;
- внутренние ссылки актуальны;
- статус изменён на `accepted` после проверки.
- заполнены обязательные поля из [[document-governance]];
- нет дубликата `artifact_id` или конкурирующего принятого документа.

## Для функции

- acceptance criteria выполнены;
- позитивные и ключевые негативные сценарии покрыты тестами;
- permissions и бизнес-инварианты проверяются на backend;
- значимые действия попадают в audit log;
- UI обрабатывает loading, empty и error states;
- документация и demo data обновлены;
- lint, format, typecheck и CI проходят.

## Для MVP

- сквозной сценарий выполняется через браузер на чистом окружении;
- API и БД обеспечивают тот же сценарий независимо от UI;
- повторный payroll export возвращает существующую запись без нового предметного эффекта;
- критические тесты стабильны;
- staging/production имеют health check и базовое логирование;
- README, диаграммы, demo script и ограничения актуальны;
- выполнен этап 12 — финальный аудит.
