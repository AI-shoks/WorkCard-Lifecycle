# Negative Scenarios

Каталог 40 обязательных отказов MVP v1. Единый постконтракт: предметные данные и версии не изменены; события успеха не созданы; клиент получает безопасный явный отказ. HTTP-детали определит [[api-contracts]].

## Порядок безопасной обработки

Backend устанавливает идентичность, проверяет право роли, загружает цели, затем проверяет data/purpose/gate/state/invariants и версии. Ошибка не раскрывает закрытые сведения. Различение HTTP-категорий не может ослабить единый постконтракт.

## Вне каталога

Поведение отрицательной приёмки, доработки, переназначения, повторного выпуска, редактирования паспорта/норм и реального payroll не моделируется: функции отсутствуют.
