# Свидетельства FA-01/02

Публичная сводка локальных результатов от 27 сентября и проверки их применимости от 28 сентября 2026 года. Она подготовлена по сохранённым оригиналам без нового запуска приложения или тестов. Основание — `4e813f5a9641abe3068d1dfc544399d557028316` плюс шесть проверенных TS-файлов; один base HEAD не идентифицирует изменённую версию.

## Доступность исходных свидетельств

Raw-логи, DOM/SQL-снимки, снимки рабочего дерева и отчёты с локальными путями сохранены в локальном архиве владельца и не входят в Git-кандидат. Здесь опубликованы только результаты, ограничения и [индекс SHA-256](evidence/fa-0102-summary.json). Это производная сводка: hashes позволяют сверить отдельно полученный оригинал, но сами по себе не доказывают выполнение проверки и не заменяют доступ к raw evidence. Для будущего CI требуются собственные отчёты того же commit и run/attempt по [[ci-pipeline]].

Состав и assertions — [[final-audit]], команды и границы — [[quality-gates]]. Четыре новых исходника/теста включены вместе с двумя изменёнными TS-файлами; все шесть SHA-256 оригинальных bytes перечислены в индексе. Контракты, SQL migrations и зависимости не меняются.

Агент выполнил узкий проход по отдельному разрешению пользователя: API из исходников через tsx и Vite production build по отчёту. Проверены семь DOM-снимков, шесть скриншотов, сведения о среде, console и независимые read-only SQL assertions.

| Финальная приёмка | UI приёмка и повторное чтение подготовленной партии; FINAL_ACCEPTED, versions 3/3/3, одно событие. Партия создана/выпущена API, 250 CLOSED карточек и допуски подготовлены owner SQL в disposable DB |

Полный 250-card lifecycle через UI не выполнялся этим smoke. Отсутствуют полный fingerprint checkout времени прохода и независимо сохранённый digest web build; список из 22 файлов их не заменяет. Из-за ошибки инструмента mouse click/drag применялись фокус и клавиатурная активация. Это ограничивает UI-доказательство и не превращает smoke в CI, проверку нового container image или hosted release. Историческое сообщение пользователя без SHA/окружения учитывается отдельно по FA-04.

## Применимость hashes

На входе документационной задачи совпали 22/22 hashes технического результата. Затем семь документов намеренно обновлены: в индексе сохранены их before/after SHA-256. На входе подготовки кандидата 15 прежних hashes совпадают непосредственно, семь — через эту цепочку; проверены все 35 hashes technical/UI evidence и исходный снимок 297 файлов с семью допустимыми обновлениями.

Эти hashes относятся к оригинальным локальным bytes, до Git-нормализации строк. After hashes семи документов описывают результат документационной задачи, а не новые редакционные изменения кандидата. В кандидате уточнены публикация evidence, ссылки, фактический workflow scope и статусы dashboard; код не изменён. Окончательную документацию определяет отдельный Git tree кандидата и его diff, сохранённые в локальном review-пакете. Исходные raw evidence не редактировались.
