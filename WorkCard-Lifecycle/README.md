# Production Work Card Workflow

Независимый portfolio case study: веб-приложение, показывающее полный цифровой жизненный цикл рабочей карточки — от выпуска производственной партии до экспорта mock нормо-часов.

## Базовый сценарий MVP v1

1. Создать синтетическую производственную партию, маршрут и нормы.
2. Выпустить `WorkCardSet` и отдельные `WorkCard` по количеству экземпляров.
3. Массово назначить карточки исполнителю.
4. Провести карточку через выполнение, подтверждение мастером и БТК.
5. Закрыть принятую карточку.
6. Экспортировать её в mock payroll без возможности двойного экспорта.
7. Показать полную историю значимых действий в audit log.

## Принцип работы

Проект развивается небольшими вертикальными срезами. Этапы задают порядок принятия решений и набор обязательных артефактов, но не превращаются в месяцы изолированной документации.
