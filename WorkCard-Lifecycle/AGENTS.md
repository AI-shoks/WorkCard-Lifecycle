# Repository instructions

- Пользовательский производственный интерфейс создаётся на русском языке.
- Производственные термины берутся из `docs/domain/glossary.md`; допустимы сокращения ПДБ, БТБ и БТК.
- Технические ID, UUID, коды ролей, enum, имена команд и событий не показываются производственным ролям и на верхнем уровне «Сведений о прототипе». Если они нужны для документации, используйте только вложенный закрытый по умолчанию блок «Технические коды для разработчика».
- Русский и английский не смешиваются без документированной причины и отсутствия принятого русского производственного эквивалента.
- После добавления нового экрана проверяется весь пользовательский UI: видимый текст, состояния, роли, мобильные подписи, `aria-label`, `aria-describedby`, `title` и tooltip.
- Технические имена команд, событий, типов и enum не переименовываются только ради перевода отображения.
- Изменения UX-copy не должны менять доменную логику, права, обработчики действий, последовательность основного процесса и навигацию.
- Перед завершением UX-copy изменений запустите read-only проверку `window.runUxCopyAudit()` в `docs/ux/prototype.html` и проверьте все 14 шагов на desktop и mobile.
